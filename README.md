# Atividade 4
Simulação de Hierarquia 

Esta atividade tem como objetivo apresentar a simulação de um ambiente hierárquico de redes, colocando em prática os conhecimentos adquiridos durante as aulas de Redes de Computadores.

Durante o desenvolvimento da atividade, foi realizada a criação de uma topologia de rede utilizando equipamentos como roteadores e switches Cisco, organizados de maneira hierárquica para possibilitar a comunicação entre os diferentes dispositivos da rede.
